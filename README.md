# Tidy

A small, calm to-do list app for Android (React Native + Expo).

- Home grid of lists with task counts (Today, Flagged, Inbox and your own lists)
- Today view with Overdue (hide / reschedule), Today, Upcoming, No date and Completed
- Month calendar with busy-day dots; repeating tasks show on future days
- Quick add bar, plus a full edit sheet: list, date, reminder, repeat, flag, link and note
- Reminders as local notifications; search; your own lists with icon and colour

The APK is built by GitHub Actions on every push to the `tidy` branch.
